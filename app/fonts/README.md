# Fonts

Self-hosted so builds never depend on a network fetch (a failed Google Fonts
download at build time fails the whole build). Latin subsets, variable weights,
from Google Fonts. All three families are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org), which permits bundling and
redistribution.

- Schibsted Grotesk — 400–800, normal + italic
- Spline Sans Mono — 400–700
- Cormorant Garamond — 500–600, normal + italic (Paradox fragments only)

Full Stack Technologies uses the brand kit’s complete variable WOFF2 fonts:

- Inter — 100–900, normal (body and UI)
- Manrope — 200–800, normal (headings)

Their SIL OFL license files are included alongside the fonts.
